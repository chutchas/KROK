# Bundled fonts

**Garuda** (TLWG) — Thai + Latin sans, used server-side by pdfkit to render
submission PDFs (`src/lib/pdf/submission-pdf.ts`). Chosen because pdfkit +
fontkit shape Thai combining marks correctly and Garuda is freely
redistributable.

Source: fonts-tlwg (https://github.com/tlwg/fonts-tlwg) · License: GPLv2 with
font exception (redistribution permitted).
