# KROK — ไฟล์แบรนด์

มาร์ค "Inspect Lens" — วงชัตเตอร์ผ่าสี่ส่วนล้อมเครื่องหมายถูก

## เลือกไฟล์ยังไง

| ไฟล์ | ใช้เมื่อ |
| --- | --- |
| `mark-auto.svg` | ฝังในหน้าเว็บ/อีเมลที่ผู้อ่านอาจอยู่โหมดไหนก็ได้ — สลับสีเองด้วย `prefers-color-scheme` |
| `mark-light.svg` | พื้นสว่าง (#ffffff / #f8fafc) เช่นเอกสาร สไลด์พื้นขาว |
| `mark-dark.svg` | พื้นมืด (#0f172a และเข้มกว่า) เช่นการ์ด navy สไลด์ดำ |
| `mark-compact-*.svg` | ขนาด 16–26px — วงตันไม่มีร่องผ่า ไม่งั้นร่องจะตันเป็นก้อน |
| `mono.svg`, `mono-compact.svg` | สีเดียวตาม `currentColor` — พิมพ์ขาวดำ ปั๊ม สลักเลเซอร์ |

ในแอปไม่ต้องใช้ไฟล์เหล่านี้ ใช้ `<LogoMark />` จาก `src/components/Logo.tsx`
ซึ่งอ่าน token `--brand-mark-*` แล้วสลับโหมดเองอยู่แล้ว

## สี

| | มินต์ | ฟ้า | น้ำเงิน | เครื่องหมายถูก |
| --- | --- | --- | --- | --- |
| Light | `#10b981` | `#0891b2` | `#2f6fe0` | `#0f172a` |
| Dark | `#6ee7b7` | `#22d3ee` | `#5b93f5` | `#f8fafc` |

ชุด light ลึกกว่า ramp หลักของ UI ตั้งใจ — มินต์ `#6ee7b7` บนพื้นขาวคอนทราสต์ราว 1.4:1 อ่านไม่ออก
ชุด dark คือ ramp หลักที่ปรับปลายฟ้า/น้ำเงินให้สว่างขึ้นบน navy

## กติกา

- ห้ามยืด — สัดส่วนจัตุรัสเสมอ
- พื้นที่ว่างรอบมาร์คอย่างน้อย 25% ของความกว้างมาร์ค
- ห้ามใส่มาร์คแบบ full บนพื้นที่เล็กกว่า 28px ใช้ compact แทน
- ห้ามเปลี่ยนสีเครื่องหมายถูกเป็นสีแบรนด์ — มันต้องเป็นสีตัวอักษรเพื่อให้อ่านเป็น "ผ่านแล้ว"
